# Мемория — локальная студия реставрации фотографий

Запуск без установки зависимостей. Нужен Python 3.10 или новее.

```sh
python server.py
```

Откройте **http://127.0.0.1:8000**. В Windows также можно использовать `py server.py`.

## Что работает

- Пакетная загрузка JPG, PNG, WebP до 25 МБ и 60 Мп на фотографию.
- Автоматическое локальное улучшение контраста, чёткости, сглаживание шума.
- Увеличение ×2 интерполяцией, ограничение результата до 16 Мп.
- Сравнение до/после, настройка контраста и резкости, сохранение и экспорт.
- Фототека, поиск по имени и клиенту, фильтры статусов.
- Клиент, стоимость, готовность и выдача заказа.
- Подключение AI-обработчика, импорт результата из внешнего редактора, ссылка на Photopea.
- SQLite и файлы на локальном диске. Оригиналы не перезаписываются.

Базовые фильтры **не удаляют крупные повреждения и не раскрашивают чёрно-белые фото**. Для этого необходима модель реставрации/колоризации. Она не поставляется с платформой. Возможность подключить её реализована через совместимый HTTP API, но ComfyUI и другие программы требуют адаптера. Иллюстрации пустой фототеки — примеры оформления, не результаты обработки.

## Подключение AI

В «Настройках» задайте адрес обработчика и необязательный API-ключ. Сервер выполняет `POST` на указанный адрес с JSON:

```json
{"image":"data:image/png;base64,…","operations":["restore","colorize"],"photo_id":"…"}
```

Обработчик должен вернуть:

```json
{"image":"data:image/png;base64,…"}
```

Поддерживаются PNG, JPG, WebP. При наличии ключа передаётся `Authorization: Bearer …`. Тайм-аут — 120 секунд, исходные файлы сохраняются при ошибке. Выбранный внешний сервис получает фото; для полностью автономной работы используйте локальный обработчик.

Внешние настольные программы запускаются пользователем самостоятельно: браузер не может безопасно запускать произвольные приложения. Скачайте оригинал из карточки, обработайте в своём редакторе и нажмите «Загрузить результат» → «Сохранить результат».

## Данные

Всё хранится в `data/`: `studio.db`, оригиналы и результаты в `photos/`. Остановите сервер и скопируйте папку для резервного копирования. API-ключ хранится в локальной базе незашифрованным, доступ ограничивайте средствами ОС. Сервер по умолчанию слушает только `127.0.0.1`; не выставляйте его в интернет, авторизация пользователей не реализована.

Можно указать другой порт: `python server.py --port 8080`. Для данных в другой папке задайте переменную `STUDIO_DATA`.

## Проверка

```sh
python -m unittest discover -s tests -v
node --check static/app.js
node tests/test_frontend.cjs
```

Python-тесты выполняют реальные HTTP-обработчики через транспорт в памяти, без открытия порта. JS-тесты проверяют обработку пикселей на тестовом canvas. Node.js нужен только для проверок, не для запуска приложения. Полноценный прогон в браузере в текущем окружении заблокирован ограничением сетевых сокетов.
