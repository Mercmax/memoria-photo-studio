# Мемория 2.1 — локальная студия реставрации фотографий

Загрузка и обработка фото, история версий, кисти ретуши, очередь заданий и заказы с несколькими фотографиями. Веб-интерфейс работает локально. Основной сервер требует только Python 3.10+; локальные нейросети устанавливаются отдельно.

## Быстрый запуск

```sh
python server.py
```

Откройте **http://127.0.0.1:8000**. На Windows можно запустить `start.bat` или `py server.py`; на macOS/Linux — `./start.sh`.

Без AI-зависимостей доступны загрузка, браузерное улучшение контраста/резкости/шума, увеличение ×2 интерполяцией, версии, сравнение, клонирующая и цветовая кисти, заказы и ZIP готовых результатов/оригиналов. Браузерная обработка требует открытой вкладки.

## Обновление с версии 1.0

1. Остановите старый сервер (`Ctrl+C`).
2. Скопируйте папку `data` в резервное место.
3. Обновите файлы программы, **сохраните свою папку `data`**.
4. Запустите сервер. Миграция добавляет новые таблицы и поля автоматически, без удаления старых фото и заказных данных. Старые результаты появятся в истории версий.

Фотографии первой версии сохраняют клиента и стоимость. Объединить их в новые групповые заказы можно в разделе «Заказы» или через выбор фото в фототеке.

## Локальные модели: Windows, RTX 4070 Super + RTX 3060, 32 ГБ RAM

1. Установите **Python 3.11** с Python Launcher и обновите драйвер NVIDIA.
2. Запустите **`setup-ai-windows.bat`**. Он создаёт отдельную `.ai-env`, устанавливает PyTorch 2.5.1 / torchvision 0.20.1 с CUDA 12.1 и зависимости. Первый запуск требует интернета и нескольких ГБ свободного места. Системный Python не изменяется.
3. Перезапустите `server.py`. В «Инструментах» появится статус обработчика.
4. Скачайте **DDColor**, **Real-ESRGAN ×2**; при необходимости GFPGAN v1.4, ×4 и Big-LaMa. Скачивание идёт через очередь, с отменой и повтором. Для GFPGAN загружаются также детектор и парсер лиц.
5. В «Настройках» оставьте устройства **автоматически** и фрагмент **256**. Сервер создаёт до двух независимых обработчиков NVIDIA. Можно выбрать карты явно по именам и номерам `cuda:N`; номер 0 не обязательно соответствует 4070 Super.
6. В студии или фототеке выберите обработчик **«Локальные модели»** и режим обработки.

Видеопамять двух карт не суммируется. Каждая обрабатывает одно задание за раз; очередь распределяет задания между свободными устройствами. Задания с приоритетом, запущенные из карточки, выбираются раньше обычных. По умолчанию восстановление лиц выключено; регулируемое смешивание с исходным лицом снижает силу изменений.

На ПК без NVIDIA установку можно выполнить командой `py -3.11 setup_ai.py --cpu`.

## MacBook M5, 16 ГБ общей памяти

Для автономного режима нужен **Python 3.11**. В папке проекта выполните `bash setup-ai-mac.sh`, затем перезапустите сервер. Установщик скачивает CPU/macOS-сборки PyTorch. В настройках выберите **CPU**, **DDColor Tiny**, фрагмент **128**. Модели запускаются последовательно на одном устройстве. Для начального набора достаточно Tiny и Real-ESRGAN ×2.

MPS отображается только при доступности в PyTorch. Он требует проверки конкретных моделей и не заявляется как проверенный на M5; для LaMa при MPS используется CPU из-за FFT. CUDA доступна только на NVIDIA. Физический M5 и NVIDIA-карты пользователя в среде разработки недоступны; установку моделей и качество результатов необходимо проверить на целевых машинах.

### Если на Mac не скачиваются модели

Обновите код, сохранив папку `data`, затем выполните `bash setup-ai-mac.sh` и перезапустите сервер. Установщик добавляет `certifi`; загрузчик, даже при запуске сервера системным Python, использует сертификаты из `.ai-env` и системный пакет `/etc/ssl/cert.pem` на macOS. HTTPS-сертификаты и имя сервера всегда проверяются.

В «Инструментах» на карточке модели теперь видны ошибка и объём скачанного; подробности также остаются в «Очереди». При ошибке сертификата в Python с python.org можно дополнительно запустить `Install Certificates.command` из папки Python в Applications. Ошибки DNS/HTTP/тайм-аута требуют проверки доступа к указанному сайту; ошибка места или прав — папки `data/models`. Нажмите «Скачать модель» или «Повторить» после устранения причины. Успешно скачанные ранее веса не заменяются недокачанным файлом.

## Работа с Mac через настольный ПК

На Windows откройте PowerShell в папке программы:

```powershell
$env:STUDIO_ACCESS_TOKEN = 'замените-на-свой-длинный-код-доступа'
py server.py --host 0.0.0.0
```

Узнайте локальный IPv4 ПК через `ipconfig`. На Mac в той же домашней сети откройте `http://АДРЕС-ПК:8000` и введите код доступа. При необходимости разрешите Python в брандмауэре Windows **для частной сети**. Вычисления и данные остаются на ПК; Mac использует браузер.

Без заданного кода сервер отказывается слушать внешние интерфейсы. Код входа сравнивается на сервере; сессия хранится в HttpOnly/SameSite-cookie и действует 12 часов до перезапуска сервера. Этот режим предназначен для доверенной домашней сети: HTTPS и публикация в интернет не настроены.

## Что делает очередь

- Задания и их настройки сохраняются в SQLite. Они продолжают обрабатываться после закрытия браузера, пока сервер запущен.
- Прогресс отражает этапы обработки; процент не прогнозирует время выполнения.
- Есть отмена и повтор после ошибки. Повтор использует тот же сохранённый источник и настройки.
- После перезапуска задания, прерванные без отмены, **начинаются заново**, а не продолжаются с конкретного пикселя или этапа.
- На успешном завершении сохраняется отдельная версия каждого этапа. При ошибке или отмене оригинал и ранее сохранённые версии остаются нетронутыми.
- Одновременно нельзя обработать или вручную перезаписать одно и то же фото. Второй сервер с той же папкой данных блокируется файловым замком.
- Внешний обработчик может продолжать свою работу после локального запроса отмены; его результат не публикуется, если задание отменено. Тайм-аут HTTP — 120 секунд.

## Редактор и экспорт

В карточке фото доступны:

- Сравнение оригинала и результата, контраст, резкость и насыщенность.
- Клонирующая кисть: `Alt` / `Option` + клик задаёт источник, обычное рисование клонирует область.
- Цветовая кисть сохраняет яркость и постепенно меняет оттенок; кисть насыщенности использует выбранное значение насыщенности.
- Маска повреждений: белая область передаётся LaMa, красная область в интерфейсе показывает маску. Кнопка «Применить LaMa» создаёт приоритетное задание. Нужна скачанная модель и AI-обработчик. Автоматическое обнаружение царапин пока не реализовано.
- Три последних мазка можно отменить. Ручные изменения нужно сохранять как новую версию. Версию можно сделать основной, включая возврат к оригиналу.
- JPEG / PNG / TIFF в **RGB 8 бит**, с sRGB-профилем и метаданными 300/600 dpi. Конвертация требует Pillow из AI-окружения. DPI не создаёт дополнительные детали и не меняет число пикселей.
- ZIP выбранных готовых результатов или оригиналов с CSV-списком. ZIP работает без AI-зависимостей.

Загрузка: JPG, PNG, WebP до 25 МБ и 60 Мп. Редактор кисти и локальные результаты ограничены **16 Мп**, включая итог после увеличения; крупные исходники уменьшаются для обработки. Оригинал сохраняется в исходном разрешении и формате. TIFF 16 бит и CMYK-экспорт не реализованы.

## Заказы

Один заказ содержит несколько фото, имя клиента, срок, пожелания, общую стоимость, предоплату и остаток. При создании и редактировании заказа можно сразу выбрать несколько новых файлов или перетащить их в форму. До сохранения видны миниатюры и имена; лишние файлы можно убрать. Можно также прикрепить свободные фото из фототеки.

Кнопка «Сохранить заказ и фотографии» создаёт заказ и последовательно загружает оригиналы с привязкой к клиенту. Если часть загрузок не прошла, заказ и успешные фото сохраняются, а форма остаётся открытой с ошибками: повторное сохранение загрузит оставшиеся файлы без повторного создания заказа. Добавление новых фото в уже готовый или выданный заказ возвращает его в работу. Обработка новых оригиналов запускается отдельно в студии/фототеке выбранным режимом. При выдаче заказа сервер проверяет, что у всех фото есть сохранённый результат. Оплаты отражаются вручную; платёжная система не подключена.

## Подключение внешнего AI-сервиса

В настройках задайте HTTP/HTTPS endpoint и необязательный API-ключ. Выберите «Внешний HTTP-сервис» для отправки фото. ComfyUI и другие программы с собственными API требуют адаптера.

Запрос: `POST`, `Content-Type: application/json`, необязательный `Authorization: Bearer …`:

```json
{
  "image": "data:image/png;base64,…",
  "operations": ["restore", "colorize", "upscale"],
  "photo_id": "…",
  "options": {"scale": 2, "face_strength": 0.35}
}
```

Ответ:

```json
{"image":"data:image/png;base64,…"}
```

Фото передаётся выбранному сервису только при запуске задания с внешним обработчиком. Ключ хранится в локальной SQLite-базе и не возвращается в браузер; его можно удалить в настройках.

## Модели и лицензии

- DDColor: [официальный код](https://github.com/piddnad/DDColor), [полные веса](https://huggingface.co/piddnad/ddcolor_modelscope), [Tiny](https://huggingface.co/piddnad/ddcolor_paper_tiny), Apache-2.0. Исходный код при установке фиксирован на commit `2adb63f2656ac41cbdf7b894cddd94121a3faf13` и сохраняет upstream-лицензию в `vendor/DDColor`.
- [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN): BSD-3-Clause.
- [GFPGAN](https://github.com/TencentARC/GFPGAN): Apache-2.0; также используются детекторы/парсер [facexlib](https://github.com/xinntao/facexlib).
- [LaMa](https://github.com/advimman/lama): код Apache-2.0. Выбранный TorchScript checkpoint скачивается из `Sanster/models`. Для коммерческого применения проверьте условия именно этих весов; лицензия кода сама по себе не разрешает использование любого стороннего checkpoint.
- CodeFormer и SUPIR не включены: опубликованные лицензии ограничивают коммерческое использование без отдельного разрешения.

Проверяйте лица и цвета перед выдачей клиенту: восстановление может дорисовывать детали, раскраска предлагает вероятные, а не доказанные исторические цвета. Файлы весов скачиваются только по фиксированным адресам каталога, временные загрузки не заменяют действующие веса до окончания. SHA-256 скачанных файлов сохраняется в manifests для учёта, это не независимая проверка подлинности.

## Данные и резервная копия

В `data/` находятся `studio.db`, `photos/` (оригиналы/версии/маски), `models/` (веса), `work/` (временные задания) и файловый замок. Для резервной копии остановите сервер и скопируйте папку целиком. Пароли/API-ключи не шифруются в SQLite; ограничивайте доступ к папке средствами ОС. `.gitignore` исключает данные, модели, AI-окружение и скачанный upstream-код из Git.

Другой порт: `python server.py --port 8080`. Другая папка данных: переменная `STUDIO_DATA`.

## Проверки

```sh
python -m unittest discover -s tests -v
node --check static/app.js
node tests/test_frontend.cjs
```

Без Pillow три теста CPU-обработчика и тест отдельного процесса пропускаются; для них установите Pillow или запустите проверки из AI-окружения. Node.js нужен только для тестов, не для работы студии. CI устанавливает Pillow и выполняет все проверки.

HTTP-тесты проверяют реальные обработчики с транспортом в памяти: сеть не требуется. Проверены миграции, версии, заказы, ZIP, доступ, очередь, конкурентное назначение заданий, отмена и восстановление. Изображения и JPEG/TIFF-экспорт проверены на CPU. JS-проверки покрывают обработку пикселей и рендер шаблонов. Полноценный браузерный прогон и нейросетевые вычисления на CUDA/MPS в текущем окружении не выполнялись.
